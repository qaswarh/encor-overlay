VXLAN & LISP Fabric

Underlay vs. Overlay Network

Underlay: The physical IP transport network (switches, routers, fiber, IGP/BGP) providing basic IP reachability. Overlay: Virtual logical tunnels (VXLAN, LISP, IPsec) built on top of the underlay to decouple virtual services from physical topology.

VXLAN — Virtual Extensible LAN (UDP 4789)

MAC-in-UDP encapsulation that extends Layer 2 segments over a Layer 3 routed underlay. Replaces the 12-bit VLAN ID (4,096) with a 24-bit VNI (16.7 million segments) and adds 50 bytes of header overhead. Performed by VTEPs (VXLAN Tunnel Endpoints).

LISP — Locator/ID Separation Protocol (UDP 4341 / 4342)

Separates who a device is (EID — Endpoint ID, its IP/MAC) from where it is attached (RLOC — Routing Locator, the Edge switch's loopback IP). Uses UDP 4341 for data plane and UDP 4342 for control plane Map-Request/Map-Reply messages.

LISP Roles (ITR, ETR, Map-Server, Map-Resolver)

ITR (Ingress Tunnel Router): Encapsulates packets entering the LISP fabric. ETR (Egress Tunnel Router): Decapsulates packets exiting the fabric. MS/MR (Control Plane Node): Maintains the EID-to-RLOC mapping database.

Cisco SD-Access & SD-WAN

Cisco SD-Access Fabric & SGTs

Uses LISP for the Control Plane, VXLAN-GPO for the Data Plane, and Cisco ISE for Policy. Embeds a 16-bit SGT (Scalable Group Tag) inside the VXLAN header for IP-agnostic micro-segmentation (SGACLs), while VRFs provide macro-segmentation (VNs).

Cisco SD-WAN Planes (vManage, vSmart, vBond, OMP)

vManage: Management plane (GUI/API dashboard). vSmart: Control plane running OMP (Overlay Management Protocol) over DTLS/TLS to distribute routes, TLOCs, and policies. vBond: Orchestration plane handling zero-touch onboarding and NAT traversal. WAN Edge: Data plane (IPsec/GRE).

Virtualization & Tunneling

VRF — Virtual Routing and Forwarding

Virtualizes a single physical router into multiple isolated Layer 3 routing tables and FIBs—allowing overlapping IP subnets across separate tenants or Virtual Networks (VNs).

GRE & IPsec Overhead (MTU Impact)

GRE (IP Protocol 47): Adds 24 bytes (20B outer IP + 4B GRE) and supports multicast/dynamic routing protocols. IPsec ESP Tunnel Mode: Adds ~50–56 bytes (AES-256 + SHA-256). Always adjust interface ip mtu 1400 and ip tcp adjust-mss 1360 to prevent fragmentation.
